# AI Studio 故事生成器

这个脚本可以自动使用AI Studio生成故事，支持批量生成和多窗口并发处理。

## 使用方法

### 基本用法

```bash
# 使用默认设置（生成2个故事）
python ai_studio_bot.py

# 生成指定数量的故事
python ai_studio_bot.py --count 5

# 简写形式
python ai_studio_bot.py -c 5

# 指定AdsPower浏览器ID
python ai_studio_bot.py --ads-id your_ads_id

# 组合使用
python ai_studio_bot.py --count 8 --ads-id your_ads_id
```

### 参数说明

- `--count, -c`: 要生成的故事数量（默认: 2）
- `--ads-id`: AdsPower 浏览器ID（默认: kyencl7）

### 安全限制

- 故事数量必须大于 0
- 建议不要一次生成超过 10 个故事，以免浏览器性能问题
- 如果设置超过 10 个故事，程序会询问是否继续

### 功能特点

1. **智能跳过**: 自动检测已生成的故事，只生成缺失的部分
2. **批量处理**: 支持生成任意数量的故事，自动分批处理
3. **并发优化**: 最多使用2个浏览器窗口并发处理，提高效率
4. **进度显示**: 实时显示处理进度和成功率统计
5. **错误处理**: 当AI生成失败时自动重试或安全退出

### 故事存储

生成的故事将保存在：`/Volumes/dhl/audio/scifi/full_story/language_code/` 目录下，文件名格式为 `{索引}.txt`。

### 依赖要求

- Python 3.7+
- playwright
- argparse（Python标准库）
- AdsPower浏览器已启动并启用本地API

### 注意事项

1. 确保AdsPower浏览器已启动并配置正确
2. 确保网络连接正常，可以访问AI Studio
3. 建议在处理大量故事时监控系统资源使用情况
4. 如果遇到生成失败，可以重新运行程序继续未完成的故事
