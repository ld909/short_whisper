# 字幕烧录工具使用说明

## 功能概述

本工具包含两个Python脚本，用于将SRT字幕直接烧录到MP4视频中，**不生成ASS文件**：

1. `burn_subtitles_to_mp4.py` - 单文件处理工具
2. `batch_burn_subtitles.py` - 批量处理工具

## 主要特性

- ✅ 直接读取SRT字幕文件，烧录到视频中
- ✅ 自动检测字幕语言（中文、英文、日文、韩文、越南文）
- ✅ 自动选择合适的字体
- ✅ 支持GPU硬件加速（macOS VideoToolbox、NVIDIA CUDA）
- ✅ 支持自定义字体大小、颜色、描边等参数
- ✅ 批量处理多个视频文件
- ✅ 自动过滤隐藏文件（如.DS_Store）

## 前置要求

1. 安装 `ffmpeg`：
   ```bash
   # macOS
   brew install ffmpeg
   
   # Ubuntu/Linux
   sudo apt update && sudo apt install ffmpeg
   ```

2. Python依赖（通常系统自带）：
   - `subprocess`
   - `argparse`
   - `logging`
   - `pathlib`

## 单文件处理

### 基本用法

```bash
python burn_subtitles_to_mp4.py -v 视频文件.mp4 -s 字幕文件.srt -o 输出文件.mp4
```

### 示例

```bash
# 基本使用
python burn_subtitles_to_mp4.py -v test/1.mp4 -s word_level.srt -o output.mp4

# 使用GPU加速和自定义字体大小
python burn_subtitles_to_mp4.py -v test/1.mp4 -s word_level.srt -o output.mp4 --font-size 20 --gpu

# 自定义颜色和描边
python burn_subtitles_to_mp4.py -v test/1.mp4 -s word_level.srt -o output.mp4 \
    --font-color FFFF00 --outline-color 000000 --outline-width 3
```

### 参数说明

| 参数              | 说明                 | 默认值         |
| ----------------- | -------------------- | -------------- |
| `-v, --video`     | 输入视频文件路径     | 必填           |
| `-s, --subtitle`  | 输入字幕文件路径     | 必填           |
| `-o, --output`    | 输出视频文件路径     | 必填           |
| `--font-size`     | 字体大小             | 16             |
| `--font-color`    | 字体颜色（十六进制） | FFFFFF（白色） |
| `--outline-color` | 描边颜色（十六进制） | 000000（黑色） |
| `--outline-width` | 描边宽度             | 2              |
| `--margin-v`      | 底部边距             | 20             |
| `--font-path`     | 自定义字体文件路径   | 自动选择       |
| `--gpu`           | 启用GPU硬件加速      | 关闭           |

## 批量处理

### 基本用法

```bash
python batch_burn_subtitles.py
```

### 示例

```bash
# 处理当前目录的所有视频文件
python batch_burn_subtitles.py

# 指定输入和输出目录
python batch_burn_subtitles.py --input-dir test --output-dir output

# 使用GPU加速和自定义参数
python batch_burn_subtitles.py --input-dir test --output-dir output --font-size 18 --gpu

# 强制重新生成已存在的文件
python batch_burn_subtitles.py --force
```

### 参数说明

| 参数              | 说明                     | 默认值   |
| ----------------- | ------------------------ | -------- |
| `--input-dir`     | 输入目录                 | 当前目录 |
| `--output-dir`    | 输出目录                 | ./output |
| `--font-size`     | 字体大小                 | 18       |
| `--font-color`    | 字体颜色（十六进制）     | FFFFFF   |
| `--outline-color` | 描边颜色（十六进制）     | 000000   |
| `--outline-width` | 描边宽度                 | 2        |
| `--margin-v`      | 底部边距                 | 20       |
| `--font-path`     | 自定义字体文件路径       | 自动选择 |
| `--gpu`           | 启用GPU硬件加速          | 关闭     |
| `--force`         | 强制重新生成已存在的文件 | 关闭     |

## GPU加速

### macOS
- 自动启用 VideoToolbox 硬件加速
- 显著提升处理速度和视频质量

### Linux
- 支持 NVIDIA CUDA 加速
- 需要安装 nvidia-smi 工具
- 自动检测GPU内存并优化设置

### Windows
- 目前主要使用CPU处理
- 未来可能支持其他硬件加速方案

## 文件匹配规则

批量处理时，工具会自动匹配视频和字幕文件：

1. **同名文件匹配**：`video.mp4` → `video.srt`
2. **同目录优先**：先在视频文件所在目录查找字幕
3. **递归查找**：在输入目录的所有子目录中查找
4. **忽略隐藏文件**：自动过滤以`.`开头的文件

## 输出文件命名

- **单文件处理**：用户指定的输出文件名
- **批量处理**：原文件名 + `_with_subtitles` + 原扩展名
  - 例：`video.mp4` → `video_with_subtitles.mp4`

## 错误处理

1. **GPU加速失败**：自动回退到CPU模式
2. **字体缺失**：使用系统默认字体
3. **文件不存在**：跳过并继续处理其他文件
4. **FFmpeg错误**：显示详细错误信息

## 性能优化

1. **视频编码**：
   - 使用 H.264 编码
   - 优化码率设置（2-3Mbps）
   - 保持音频不变（copy模式）

2. **处理速度**：
   - GPU加速：比CPU快3-5倍
   - 多线程CPU处理
   - 智能缓存和预处理

## 实际使用示例

    --outline-color 000000 \

## 注意事项

1. **输出文件大小**：烧录字幕后的文件可能比原文件略大
2. **处理时间**：取决于视频长度和是否使用GPU加速
3. **字体路径**：确保字体文件存在，否则使用系统默认字体
4. **磁盘空间**：确保有足够的磁盘空间存储输出文件
5. **覆盖提醒**：默认会覆盖同名输出文件，使用`-y`参数

## 常见问题

### Q: FFmpeg未找到怎么办？
A: 请先安装FFmpeg：`brew install ffmpeg`（macOS）或 `sudo apt install ffmpeg`（Linux）

### Q: 字幕显示不正确怎么办？
A: 检查字幕文件编码是否为UTF-8，并确认字幕语言检测是否正确

### Q: 处理速度很慢怎么办？
A: 使用`--gpu`参数启用硬件加速，可显著提升处理速度

### Q: 自定义字体不生效怎么办？
A: 确认字体文件路径正确，并且字体文件可读

### Q: 批量处理时某些文件失败怎么办？
A: 工具会跳过失败的文件并继续处理其他文件，检查日志了解具体错误原因
