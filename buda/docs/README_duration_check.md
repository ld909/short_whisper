# 视频时长检查功能说明

## 概述

`add_subtitles_to_mp4.py` 脚本现在包含了自动时长检查和重新生成功能，可以确保生成的带字幕视频与原始视频的时长差异在可接受范围内。

## 新增功能

### 1. 时长差异检查
- 自动获取输入视频和输出视频的时长
- 计算两者之间的时长差异
- 设置阈值为 5 秒，超过此阈值将触发重新生成

### 2. 自动重新生成
- 如果检测到已存在的输出文件时长差异过大，自动删除并重新生成
- 如果新生成的视频仍有时长问题，自动使用简化模式重新生成
- 提供详细的日志信息，便于问题排查

### 3. 简化模式回退
- 当标准模式生成的视频出现时长问题时，自动切换到简化模式
- 简化模式使用更稳定的编码参数，减少时长差异的可能性

## 工作流程

```
1. 检查输出文件是否存在
   ↓
2. 如果存在，检查时长差异
   ↓
3. 如果差异 > 5秒，删除输出文件
   ↓
4. 使用标准模式生成新视频
   ↓
5. 验证新生成视频的时长
   ↓
6. 如果仍有问题，使用简化模式重新生成
   ↓
7. 最终验证并完成
```

## 使用方法

### 基本使用
```bash
# 处理所有语言的视频（会自动进行时长检查）
python add_subtitles_to_mp4.py

# 处理特定语言
python add_subtitles_to_mp4.py -l en ja

# 处理单个视频
python add_subtitles_to_mp4.py -s "频道名/视频名"
```

### 强制重新生成
```bash
# 强制重新生成所有视频（忽略现有文件）
python add_subtitles_to_mp4.py -f

# 强制重新生成特定视频
python add_subtitles_to_mp4.py -f -s "频道名/视频名"
```

## 配置选项

### 时长差异阈值
可以通过修改脚本中的 `DURATION_DIFF_THRESHOLD` 常量来调整阈值：

```python
# 时长差异阈值（秒）
DURATION_DIFF_THRESHOLD = 5.0  # 可以根据需要调整
```

### 支持的视频格式
- 输入：MP4 格式
- 输出：MP4 格式
- 使用 ffprobe 获取视频信息

## 测试功能

可以使用提供的测试脚本验证功能是否正常：

```bash
python test_duration_check.py
```

测试脚本会：
1. 创建不同时长的测试视频
2. 验证时长获取功能
3. 验证时长差异检查功能
4. 验证错误处理功能

## 故障排除

### 常见问题

1. **ffprobe 不可用**
   - 确保安装了 ffmpeg 工具包
   - 检查 PATH 环境变量

2. **时长获取失败**
   - 检查视频文件是否损坏
   - 确认文件格式是否支持

3. **重复重新生成**
   - 检查输入视频和字幕文件是否匹配
   - 考虑调整时长差异阈值

### 调试建议

1. 查看详细日志输出
2. 使用测试脚本验证基本功能
3. 手动检查问题视频的时长信息：
   ```bash
   ffprobe -v quiet -print_format json -show_format input.mp4
   ```

## 性能影响

- 时长检查增加了少量处理时间（每个视频约 1-2 秒）
- 重新生成会显著增加处理时间，但确保了输出质量
- 建议在批量处理时预留额外时间

## 兼容性

- 支持 macOS 和 Linux 系统
- 需要 ffmpeg 和 ffprobe 工具
- Python 3.6+ 版本
